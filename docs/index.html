기능 목록
  • 🔍 자동 감지 (UDP Broadcast) — 계정 가입·서버 설정 없이, 실행만 하면 같은 LAN 사용자 자동 발견
  • ✉️ 1:1 즉각 팝업 쪽지 — 수신 즉시 화면 중앙에 쪽지 팝업! (메신저가 아닌 쪽지 감성)
  • 📁 파일 드래그 앤 드롭 — 쪽지 창에 파일을 끌어다 놓으면 다중 파일 전송 (진행률 표시 + 취소 가능)
  • 🗂️ LAN 공유 폴더 — exe 옆 share 폴더를 읽기 전용 공개 (TCP 50507), 📁 버튼으로 탐색·다운로드 (진행률 표시)
  • 📊 LAN 진단 · 내보내기 — 선택된 IP, 브로드캐스트 대상, 패킷 시간, 피어 목록 확인 + 진단 정보를 바탕화면 txt로 저장
  • 📝 롤링 로그 — %AppData%\Y-popup\logs에 일별 로그 저장 (7일 보관)
  • 🌙 부재중 · 자동 답장 — 자리 비움 시 부재 표시 + 자동 응답 (유휴 감지는 Windows)
  • ☎ 트레이 상주 — 파란 전화기 아이콘, Windows 시작 시 트레이 전용 실행(--tray) 지원

01 파일 다운로드
상단 다운로드 표에서 OS에 맞는 파일을 선택하세요.
Windows 64-bit (권장): Y-popup.exe — 설치 불필요
macOS: .dmg 이미지를 열어 Y-popup.app을 응용프로그램 폴더로 복사한 후 실행 (최초 실행 시 보안 허용 필요할 수 있음)
02 방화벽 규칙 허용
첫 실행 시 방화벽 알림이 뜨면 [허용]을 클릭하세요.
포트: UDP 50505, TCP 50506, 공유폴더 TCP 50507
(설정 → 네트워크 → 방화벽에서 규칙 추가 가능)
03 트레이에서 관리
실행 후 화면 우측 하단 트레이의 파란 전화기 아이콘을 클릭하면
사용자 목록·설정·LAN 진단·정보를 열 수 있습니다.
탐색이 안 되면 «LAN 진단»에서 네트워크 상태를 확인하고, 필요 시 내보내기로 진단 파일을 저장하세요.
04 공유폴더 · 쪽지
사용자 선택 → 쪽지 보내기 (파일은 첨부 또는 드래그 앤 드롭).
목록의 📁 아이콘으로 상대 공유폴더를 탐색·다운로드할 수 있습니다.
공유할 파일은 실행 파일 옆 share 폴더에 넣으세요.
