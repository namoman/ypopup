기능 목록
  • 🔍 자동 감지 (UDP Broadcast) — 계정 가입·서버 설정 없이, 실행만 하면 같은 LAN 사용자 자동 발견
  • ✉️ 1:1 즉각 팝업 쪽지 — 수신 즉시 화면 중앙에 쪽지 팝업! (메신저가 아닌 쪽지 감성)
  • 📁 파일 드래그 앤 드롭 — 쪽지 창에 파일을 끌어다 놓으면 다중 파일 전송
  • 🌙 부재중 · 자동 답장 — 자리 비움 시 부재 표시 + 자동 응답 메시지
  • 🗂️ LAN 공유 폴더 — exe 옆 share 폴더를 읽기 전용 공개 (TCP 50507), 📁 버튼으로 탐색·다운로드
📖 시작하기 안내
×
01 파일 다운로드
일반 사용자: Y-popup.exe (런타임 포함, 설치 불필요)
용량 절약: Y-popup-net8.exe + .NET 8 Desktop Runtime 설치
02 방화벽 규칙 허용
첫 실행 시 방화벽 알림이 뜨면 [허용]을 클릭하세요.
포트: UDP 50505, TCP 50506, 공유폴더 TCP 50507
(설정 → 네트워크 → 방화벽에서 규칙 추가 가능)
03 트레이에서 관리
실행 후 화면 우측 하단 트레이의 파란 전화기 아이콘을 클릭하면
사용자 목록과 설정을 열 수 있습니다.
